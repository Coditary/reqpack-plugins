# rqp-plugin-tempify

ReqPack plugin for [Tempify](https://github.com/Coditary/Tempify) — template-based project scaffolding.

`default-template-repositories.json` points at the [Coditary/tempify-registry](https://github.com/Coditary/tempify-registry) catalog (`templates.json`).

## Install

From this directory:

```bash
rqp install .
```

Or install the plugin bundle from wherever ReqPack resolves plugin sources.
