# rqp-plugin-beez

ReqPack plugin for [Beez](https://github.com/Coditary/Beez) — workflow plugin manager.

`default-plugin-repositories.json` points at the [Coditary/beez-registry](https://github.com/Coditary/beez-registry) catalog (`plugins.json`).

## Install

From this directory:

```bash
rqp install .
```

Or install the plugin bundle from wherever ReqPack resolves plugin sources.
