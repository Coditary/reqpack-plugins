# rqp-plugin-ycallr

ReqPack plugin for [ycallr](https://github.com/Coditary/ycallr-cli): API profile catalogs and `.rqp` package installs.

`default-package-repositories.json` points at the [Coditary/ycallr-registry](https://github.com/Coditary/ycallr-registry) catalog (`packages.json`).

## Install

From this directory:

```bash
rqp install .
```

Or install the plugin bundle from wherever ReqPack resolves plugin sources.
